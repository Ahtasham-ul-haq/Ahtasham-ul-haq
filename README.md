### Imaginify — AI-Powered Image Editing SaaS

> Upload a photo, let AI do the heavy lifting — background removal, object removal, generative fill, and more. Built with a full billing system via Stripe.

Built to understand how to wire together third-party AI APIs, handle image transformations at scale with Cloudinary, and ship a product with real payment flows. The most technically involved project I've done so far.

**Stack:** Next.js · TypeScript · MongoDB · Cloudinary AI · Stripe · shadcn/ui
